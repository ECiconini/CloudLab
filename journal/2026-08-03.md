Hoje realizei a instalação do ubunto server, configurando tudo pelo CLI.

Além disso consegui realizar a conexão do meu desktop windows no notebook no qual o ubunto esta instalado via SSH.

SSH é a sigla para "Secure Shell", no SSH temos o Cliente SSH e o Servidor SSH.

Cliente  SSH: Quem vai realizar a conexão.
Servidor SSH: Onde a conexão será efetuada, ou seja o próprio servidor.


Pelo notebook utilizei o comando "which" que verifica onde está o executavel de certo comando, no caso utilizando o
"whitch ssh" ele procura o executavel do comando ssh.

Realizei também a procura do sshd que é o "SSH Daemon" que é o programa que aguarda as conexões de "fora" dos clientes
SSH pela porta 22.

Além disso também verifiquei se o serviço do SSH estava funcionando corretamente por meio da ferramenta "systemctl".
Podemos utilizar o "systemctl" das seguintes maneiras:

"systemctl start ssh" ---> está iniciando o serviço SSH.

"systemctl stop ssh" ---> está parando o serviço SSH.

"systemctl restart ssh" ---> está reiniciando o serviço SSH.

"systemctl status ssh" ---> mostra o status do serviço SSH.

"systemctl enable ssh" ---> faz com que o serviço SSH inicie automaticamente quando o computador ligar.

(Lembrando que podemos utilizar essea ferramente com qualquer serviço, o SSH acima está sendo utilizado de exemplo.)
